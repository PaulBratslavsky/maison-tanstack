# Maison on TanStack

A demo for a fictional luxury house: a LINE app, an AI concierge and staff in the Strapi admin all work through one Strapi plugin and Strapi's MCP server. This is the TanStack edition: the customer app is TanStack Start, and every model call goes through TanStack AI.

It rebuilds [maison-demo](https://github.com/PaulBratslavsky/maison-demo). Work has not started yet. See `docs/spec.md` for what it will be, and `HANDOFF.md` for how to build it.
